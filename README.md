## 原本から確認した仕様

> ⚠ 以下に正解の暗号を含みます。プレイヤーに見せないでください。

- **正解**: `SON`（コード内では文字コード `[83,79,78]` として記述）
- **ダイヤル**: 3つ。各ダイヤルは `<select>`（タップでリストから選ぶ方式）。
  - 選べる文字は全26文字ではなく **A, E, I, L, N, O, R, S, T, U の10文字のみ**。
  - 初期表示は `A / A / A`。
- **回答回数**: 3回。不正解ごとに1減る。
- **不正解時**: 錠が左右に揺れるアニメーション（0.36秒）と「解錠できない。残りN回。」の表示。
- **3回失敗後**: 「解錠できなかった。錠はもう動かない。」を表示し、ダイヤルとボタンが無効になる。「最初からやり直す」リンクが出る。
- **正解時**: シャックル（U字部分）が持ち上がって傾く演出（0.65秒）→「錠が外れる音がした。」→ 0.65秒後に全画面の結果カード（◇ / UNLOCKED / 解錠できました / 錠が静かに外れた。 / 最初からやり直す）。
- **保存方式**: `localStorage` のキー `requiem-dial-lock-v2` に `{attempts, solved}` を保存。
  - **再読み込みしても残り回数・解錠済み状態は保持される**（同じブラウザ内）。
  - ダイヤルの位置は保存されず、再読み込みで A/A/A に戻る。
  - 「最初からやり直す」でキーを削除して初期化。
- **キーボード**: Enter キーで「解錠を試みる」と同じ動作。
- **レスポンシブ**: 幅540px以下でスマホ用レイアウトに切り替え。

## ローカルで動かす

```bash
cd このフォルダ
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

`index.html` を直接ダブルクリックしても動きます。

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリのルートに置いて push
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、ブランチ `main` / フォルダ `/ (root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

注意: 公開すると `script.js` は誰でも読めるため、ソースを見れば正解が分かります（原本も同じ構造）。

## 公演前のリセット

`localStorage` は端末・ブラウザごとに残ります。同じ端末を使い回す場合は、各回の前に「最初からやり直す」を押すか、ブラウザのサイトデータを削除してください。
